# 2026-10-27 连击奖励上限与难度曲线

高波次（蜂群把单波推到48架）时，连击窗口内连续击毁会让单次连击奖励线性膨胀：`60 × (combo-1)`，20连击就是1,140金币，足以让经济失去意义。本轮加上限，并把实际难度曲线写进文档。

## 改动

- `SiegeSettings.comboBonusCap`（默认300，0表示不限制）：单次连击奖励的上限。
- 连击奖励改为纯函数 `SiegeSession.ComboBonusFor(combo, perKill, cap)`，`TickKillStreak` 只负责取参数与发放；这样上限与起点都能在无场景的规则检查里覆盖。
- `Docs/SiegeWarfare.md` 增加“难度曲线（默认配置）”表：按默认参数列出第1–27波的来袭数量，标出蜂群/精英的出现波次、第15波的优先级、第24波起被48上限截断，以及单波收益构成。

## 验证

| 验证 | 结果与边界 |
| --- | --- |
| 规则检查 | `SiegeCombatFeedbackChecks.Run()` 增至 **25项**并全部通过，新增“第二次击毁起才有连击奖励（combo1=0、combo2=60）”和“上限生效（10连击、60单价、300上限=300；上限0时=540）”。 |
| 编译 | Unity 6000.3.11f1 编译通过。 |
| 文档 | 难度曲线按当前默认参数计算：3/6/9/12/18/21/24波为蜂群，5/10/15/20/25波为精英，第15波精英优先，第24波起蜂群被48上限截断。 |

## 未验证

- 没有跑长时间自然对局验证“上限300”在后期是否仍然偏松或偏紧；这是设计判断，不是实测平衡结论。
- 难度曲线表是公式推导，未覆盖“同屏上限6”导致的延迟生成时间，也没有考虑玩家舰艇强度差异。
