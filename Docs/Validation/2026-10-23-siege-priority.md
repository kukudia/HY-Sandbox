# 明确任务目标的远程追击

2026-10-23，Unity 6000.3.11f1。大型建筑基地的核心相对建筑根有偏移，敌舰围绕核心在130m半径生成；同种子首舰距建筑根151.57m，超过EnemyController默认150m。旧实现把明确指派目标也按自主索敌范围过滤，接近输入又有第二道距离门控，增援因此可能没有进攻意图。

生产改动只区分两种来源：有效的明确任务目标可在远处被选中并产生接近输入；普通自主发现继续受detectionRange限制。禁用、同阵营、非运行/模拟、不同场景和守卫范围校验保持。现有SetPriorityTarget的生产调用者仅SiegeWaveDirector，不改Inspector、Prefab、动力、武器或通用索敌半径。
