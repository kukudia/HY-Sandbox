# 战斗航向连续衔接

范围为 EnemyController 战斗追击/绕障；未修改机库出入库航线。

检查发现低频决策将参考速度方向直接切换，GetVelocityInput立即抵消旧方向速度；接敌范围外的全速接近与范围内45%航速横移也直接切换。现增加每物理步连续参考航向：普通转弯90度/秒，独立航速变化6m/s²，进入接敌范围前8米渐进混入横移。新参数保留Inspector编辑入口，沿用原方向死区与决策保持。紧急避障/任务结束直接切换参考速度，保持及时制动。

验证：Unity 6000.6.8f1 导入编译通过；NavigationCombatPlayChecks 36项、AiUpgradePlayChecks 21项通过。新增检查覆盖折返参考航速不穿零、逐物理步限角、收敛新航向、停止立即制动、紧急绕过平滑。dotnet build 0错误、36个既有警告；CodeReadability 417脚本、0差异/错误；本次文件diff检查通过。全工作区原有UserSettings布局行尾空格保持原样。

参考速度连续不代表真实舰船恒速；实际转弯受推进器、负载、侧滑和障碍约束。尚未复现用户当时具体战斗场景，复杂墙角及多舰密集战斗仍需观察。暂停并非来自逐点路径（当前无全局航点）；本轮处理已确认的参考速度和接敌行为突变。
