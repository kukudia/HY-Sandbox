# 移除 NavMesh 与降低变向频率

当前生产实现为 EnemyController 的直接航向、优先爬升、稳定局部球扫。已删除 EnemyNavigationWorld、EnemyNavigationPath、安装菜单和对应 meta；Main、Siege、WorldLab、EnemyAvoidanceLab 移除导航组件，试验场和制作工具不再重烘焙。未使用的 com.unity.ai.navigation 包通过 PackageManager 移除。Unity 场景文件内置 NavMeshSettings/m_NavMeshLayer 是引擎序列化基础字段，不代表仍有导航服务。

驾驶采样从导航模式的0.1秒改为最低0.5秒；航向保持1.5秒、12度死区，近距离危险允许立即打破保持；绕行侧不跟随每次命中法线翻转，脱离障碍后仍保持3秒；接敌横移每6秒才换侧。速度补偿和输入平滑每物理步继续执行，不推迟制动。原参考速度6m/s通过FormerlySerializedAs迁移为cruiseSpeed，其他现有玩法参数保留。

## 验证边界

初次取消全局路径后，错列墙测试在90秒超时、9次接触：高空探测没发现常规高度上的下一面墙，导致两墙间下降。现前向翻越扫描同时覆盖常规高度的走廊，提前保持连续墙净空，并新增实际物理查询回归；最终实船结果采用修正后重跑。

移除全局路径搜索后，不能保证找到封闭迷宫、超出爬升高度或顶棚下凹形障碍的出口；这些布局需要单独飞行调参。现有四种高墙场景主要验证优先翻越与低频驾驶，未覆盖多舰会车和流式世界性能。没有同条件旧版航向计数，因此不声称变向次数降低百分比。此前NavMesh与避障文档仅为历史记录，当前行为以DEVELOPMENT和本文件为准。
