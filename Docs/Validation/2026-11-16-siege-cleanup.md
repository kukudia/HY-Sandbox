# 波次扫描与敌方残骸回收 · 2026-11-16

采用扫描线+HUD计数+有界回收粒子。4秒扫描，默认每0.25秒至多6个残骸；最短物理展示期仍服从Salvage配置（当前10秒）。扫描不阻塞下一波，开启新战斗立即取消。未达到保留期时扫描重复掠过，HUD保留待处理计数。友军残骸/建筑不由此清理或恢复；回收原规则产生掉落物，不增加额外金币，存量掉落不强制消失。

五场景保存真实组件和引用；Assets/Siege/Cleanup保存可编辑URP材质与ParticleSystem Prefab。粒子复用MaterialBreakEffect活动预算，不生成物理碎片。扫描HUD已因实际截图发现标题重叠而移至标题下方。
