# SiegeGameplay 航向稳定验证（2026-11-12）

## 复现与改动

从 MainMenu 选择个人 Combat Courtyard，部署 Spaceship、Swordfish，选择 CODEX_E01_Finch 开始第一波。修复前两友舰在实战采样中均出现约0.42–0.43rad/s（24°/秒）偏航角速度，航向从约190°变化到230–240°。这是两个离散状态观察，不是固定条件性能基准。

推进器经 AddForceAtPosition 施力会产生偏置转矩；旧悬浮姿态修正仅在舰体倾斜时工作，水平后跳过修正，也不保存航向参考。修复在原有供电、驾驶舱有效性、组件归属门控内增加独立偏航保持：首次接管捕获当前航向，最短角误差产生目标角速度（限制1rad/s），指数响应平滑修正实际偏航。仍沿用悬浮辅助驾驶的刚体角速度输出，不锁定 Rigidbody 旋转，不改写姿态或移动输入。

Heading Response 默认5/秒，可在悬浮控制器Inspector调整，0关闭。停供、禁用、重新归属时清除参考；下一次接管捕获当前朝向。未新增自动朝向敌人的规则。控制计算常量开销，无新扫描、分配或A*调用；本轮未做CPU性能基准。

## 实际验证

- Unity 6000.6.8f1 已导入和编译；同一基地、同两友舰及攻击机第一波实战记录65.39模拟秒，每友舰66次采样。证据：`Temp/Siege/heading-combat.csv`。
- Spaceship航向173.292–186.931°，Swordfish航向173.095–185.603°；均未持续绕圈，仍有约13°范围的摆动。一架存活Finch航向233.541–233.619°。记录期间友舰保持AI与悬浮控制启用。
- `HoverControlPlayChecks.Run` 16项通过：水平偏航衰减、359°跨1°最短纠正、重新启用捕获新航向、失电无姿态输出，以及原有无驾驶舱、推进限速、组件禁用、归属转移检查。证据：`Temp/Siege/heading-regression.txt`。
- `dotnet build HY-Sandbox.sln --no-restore --nologo`：0错误，37个既有警告。
- 代码可读性检查：438脚本，0错误；函数图/导航已同步。
