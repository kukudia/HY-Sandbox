# 建造旋转网格锚点与尺寸奇偶对齐

## 规则与修正

上一版把需求误解为“世界几何中心完全不动”，85 项检查验证的是该错误规则，不能证明用户要求的奇偶尺寸对齐正确。本版替换实现与验收条件。

实际规则以现有驾驶舱的整数边界网格为准：固定整数锚点，尺寸为奇数的轴带半格中心偏移，偶数轴中心为整数。此前偶数轴带半格的定义已更正；不能将旧测试数量视为该错误映射的正确性证据。以2×1×1绕世界Y正向旋转为例：

```text
(0, 1.5, 0.5) -> (0.5, 1.5, 0) -> (0, 1.5, 0.5) -> (0.5, 1.5, 0) -> (0, 1.5, 0.5)
```

`BuildPlacementGeometry.CalculateRotationPosition` 先移除旧姿态下世界尺寸的正半格偏移，得到中心所在整数格的锚点；再加新姿态下的正半格偏移。偏移只取尺寸奇偶，与轴的正负无关，因此180°不额外平移一格。运算使用整数格与整数半格，不把浮点包围盒尺寸加回坐标。对于默认 gridSize=1，结果为精确整数或半整数；其他网格尺寸仍受该尺寸本身的浮点表示限制。

键盘和拖拽共用该规则。世界轴旋转左乘原姿态，经 `SnapRotationToGrid` 规范化；拖拽步进从 15° 改为 90°，与既有 BlockData / Awake 的正交姿态契约一致。拖拽平面与角度参考始终使用起始中心，候选位置重新计算，避免下一帧参考点跟随偏移。

阻挡按新位置与新姿态联合检查，失败不写位置、姿态、保存或历史。Undo/Redo 同时恢复两者。放置仍按真实连接点解算；`RemoveGridNoise` 只清理距离半格不超过 gridSize×0.0001 的尾差，不强制吸附有意偏离网格的连接点。移动吸附同样清理末尾误差。

## 实际验证

- Unity Editor 6000.3.11f1，目标工程 D:/git_projects/Unity/HY-Sandbox，导入/重新编译：0 错误/0 警告。
- Main 确认未脏化后切换至隔离空场景进入 Play，运行 [BuildRotationProbe](../../Tools/Validation/BuildRotationProbe.cs)：460 项通过。退出后恢复 Main，未保存场景或写入用户蓝图。
- 1×1×1、2×1×1、2×2×1、2×2×2 真实 Prefab 的连接点放置、实例化，以及各16个正交姿态下放置中心的精确半格坐标通过。
- 虚拟键盘 W 从 Y=90°姿态绕世界 X 旋转，使用四次解析坐标解逐分量严格比较；覆盖四种尺寸、Undo/Redo。
- 虚拟鼠标真实相机射线/平面拖拽，输入角15°/30°/60°/90°/150°/0°/-90°/90°，验证其量化到90°及对应中心；释放只提交一次，Undo/Redo 通过。
- 真实 PhysX 阻挡拒绝旋转，原位置、姿态、保存计数、历史均不变。
- 用户2×1×1例子的真实 D 键操作四次循环，精确位置通过；每次以 BlockData 经过内存 JSON 序列化/反序列化，再实例化 Prefab 验证 Awake 与姿态往返。
- 原点、负坐标偏移(-10,-4,-8)、远处偏移(123,20,456)各连续100次Y旋转，逐坐标使用 == 严格比较，半格换轴且无累计尾差。没有使用 Vector3 的近似相等替代精确坐标验收。
- `dotnet build HY-Sandbox.sln --no-restore`：0错误/4个既有警告（3个依赖版本冲突、1个过时诊断API）；319份自有脚本可读性检查无差异/无错误，源码导航与函数图已刷新，`git diff --check`通过。

复现命令（先在无 SaveManager 的隔离空场景进入 Play）：

```powershell
unity command run_script --file Tools/Validation/BuildRotationProbe.cs --entry BuildRotationProbe.Run --result-only
```

机器结果写入本地临时文件 Temp/build-rotation-probe.json，不提交缓存。探针只创建临时对象/虚拟输入，保存回调仅采样内存；Undo/Redo 的真实保存入口因空场景没有 SaveManager 直接返回。

## 验证边界

未进行人工鼠标手感、完整文件仓加载或独立 Player 验证。JSON测试覆盖 BlockData 与 Awake，不代表整套保存/加载UI。固定网格锚点保证网格坐标与尺寸奇偶正确，不保证任意旋转后仍与原连接面接合；真实阻挡仍会拒绝与邻块重叠的候选姿态。
