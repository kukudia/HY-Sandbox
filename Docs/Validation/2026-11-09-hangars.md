# 机库建造与返航验证（2026-11-09）

项目：HY-Sandbox；Unity 6000.6.8f1，已连接Editor。范围包括Base Workshop、新版SiegeGameplay和独立预研Siege。保留原有UserSettings两处未提交修改，不写玩家设计或战损回原稿。

## 交付与资产

- 实体Prefab `Assets/Resources/Hangars/Hangar.prefab`、Floor/Shell/Door/Capacity四个材质、Limits配置；通过Editor API制作并保存，脚本与资源均带meta。
- 自制Unity primitive几何，Y-up米制、中心pivot、+Z门向；默认外20×9×24m、净空18×8×22m，底顶各0.5m、侧后门1m。8个立方几何约96三角形，4面共24个世界UI按钮。航行只在达到位置/速度/角度容差后精确校准最终泊位，避免等尺寸舰体因残余误差挡门。门为FixedUpdate程序动画，时长可配，不依赖外部动画版权或不可编辑烘焙。
- 数量上限6与尺寸独立；设计预算单价、门时长、耐久/质量、起飞返航速度、失能宽限及超时在资产/Inspector内可改。
- 原预研基地布局保留并扩展为BastionHangars，三个可容现有示例舰的机库取代方形占位。正式StarterHangar在原StarterBase旁增加一库；原两个JSON保持。已有玩家基地不自动插入机库。
- 普通模块预算仍每体积格5；机库按外壳面积单价1，默认示例可在20000预算内使用。正式底座边界增至64×64。
