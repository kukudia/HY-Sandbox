# Unity 6000.6.8f1 升级适配

日期：2026-11-05。目标是先解除升级后的编译阻塞，再给出有项目证据的后续适配清单；本报告不代表完整平台/画面验收。

## 当前版本与修复

- Editor：6000.6.8f1 (237b6593792b)，连接到本工程的 Editor 实际导入、编译并执行探针。
- Packages：URP / VFX Graph 17.6.0、Input System 1.20.1、UGUI 2.6.0、AI Navigation 2.0.16、Test Framework 1.8.0、Pipeline 0.7.0-exp.1。版本来自现有 manifest；本轮没有额外升级包。
- 首批运行时 9 个错误来自禁用的 GetInstanceID；后续 Editor 编译暴露 4 个错误，分别为 objectReferenceInstanceIDValue 和 UnityStats.batches。
- 对象身份比较、连接缓存、表现探针集合与拓扑基准改用 EntityId；缺失引用检查使用 objectReferenceEntityIdValue / EntityId.None。没有将身份压缩成哈希作为相等性依据。
- 电网无向边使用 EntityId.CompareTo 保证仅一端绘制；范围签名只在原有哈希用途使用 GetHashCode。敌机相位限制在一圈内，避免大 ID 转 float 后丢失时间增量；个体初始横移相位会改变，横移频率和强度不变。
- 显式无序的 FindObjectsByType 查询迁移到新版无排序参数重载，保留 inactive 查询选项；Blueprints 下相关 eval 工具同时适配。
- 世界性能探针将移除的 batches 指标替换为 drawCalls，并同步标签。这是新的指标名称/口径，不与历史 batches 数值直接比较。
- 同步 AGENTS.md、DEVELOPMENT.md 的版本和 Docs/CodeIndex.md 行号。调用链未变化，Docs/RuntimeFlow.md 仍适用。
- 不修改现有脚本 GUID、自有序列化字段名称、场景或蓝图数据格式。EntityId 仅作会话内身份，存档继续使用原有字符串身份。
- 既有 BlockCsvAuthoring 自动同步保存 25 个 Prefab，其中 16 个产生磁盘差异：说明文字折行归一化，以及 Unity 自身的 Light serializedVersion 12→13、m_ShadowRadius→m_ShapeRadius、VFX m_ResourceVersion→m_ReleaseInstanceOnDisable 迁移。已检查完整差异，没有玩法数值或 GUID 改动。工具自动保存的原始字节和哈希备份在 Library/BlockDataTable/Backups/20261105-154151-395096e29e944fdd97fd035b4d93f9c1；本轮保留这些真实 Editor 保存结果。
