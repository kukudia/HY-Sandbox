# 整舰身位与侧滑预测避障

## 实现

EnemyController 水平探测由中心 SphereCast 改为整舰碰撞体世界 AABB BoxCast，复用 EnemyObstacleClimb.GetHullBounds；排除触发器、自身及已脱离刚体的模块。保留原最小水平探测半径，实际舰体水平外扩0.25m。预测距离至少为实际水平速度乘1.5秒且覆盖下一次决策；航迹明显不同于意图时额外检测速度方向及保持中的航向，每轮最多5次扫掠。舰体边界缓存每秒更新碰撞体列表、每次决策重算实时范围。

偏侧障碍选择另一侧绕行并保持侧向，维持0.5秒决策、1.5秒航向保持、12度死区和3秒绕行侧保持。紧急近障可打破航向保持。初始重叠用几何分离方向，中心位于碰撞体表面/内部时用最近包围盒面，避免地板变成水平墙。Debug 绘制实际扫掠盒终点和法线。

## 边界

AABB 对斜向舰体及不规则舰形较保守，尚未验证旋转穿狭缝、顶棚下复杂凹形障碍、多舰会车和流式世界性能。四组实船布局允许爬升，主要检验越障与低频驾驶回归，不能代表纯水平规划或完整实战验收。无 NavMesh 或全局路径规划。
