# 直航锁定：不持续微调

> 范围补充：本记录的直航角度是导航期望方向，未证明实际推进喷口稳定。Type 03 后续实测发现执行层仍在摆动，已独立修复并记录于[模拟输入与实际喷口回归](2026-11-15-propulsion-input.md)。

## 当前规则

用户明确要求需要直行的路段不微调；上一版连续平滑已撤下，改为 `EnemyController.StabilizeDirection` 保存直线起点与方向，普通直航直接原样返回该方向。每轮感知的小幅目标偏移不插值、不累计，也不因导航拥有驾驶权而自动解锁。

- 目标方位变化达到 `directionDeadZone`（默认12度）才重选普通航向；重选后至少保持 `directionHoldTime`（默认1.5秒）。
- 目标身份切换、进入局部绕障、首次接入规划路线、同一路线实际跨过航点时可换向。仅路线版本变化不当作拐点，避免重规划驱动微调。
- 实际横向偏离锁定直线超过 `straightCourseTolerance`（新增Inspector参数，默认1.5米）才重新接入航线。锁定期不会反复纠正容差内的偏差。
- 近距离战斗横移与紧急避障可立即接管。参考速度保留 `FlightControlMath.StepCourse` 的角速度和加速度限制，必要转弯由真实推进器执行。
- 字段身份、既有配置、供电/推力标定和悬浮姿态控制保留。没有修改用户的场景或悬浮控制Prefab，也没有新增场景组件。

悬浮响应与航迹限速计算仍归类于 `Flight/FlightControlMath`；直线方向承诺属于导航策略，不调用连续响应计算。函数图与代码导航已更新。旧[平滑试验记录](2026-11-15-flight-course-stability.md)已标为历史。

## 直接行为检查

`FlightCourseChecks.Validate()` 在隔离的导航状态上调用真实控制器，结束恢复所有字段与计数：

1. 连续20次交替正负8度目标偏移，每次输出均与初始锁定方向相同，向量差平方小于1e-10。
2. 仅改变导航驾驶权仍不会让8度小偏移改变直航方向。
3. 25度明确方位变化可重选直线，普通保持期内不会立刻选回反向。
4. 实际横偏超过容差时，允许小角恢复路线；紧急方向可立即接管。
5. 6m/s参考速度的180度转弯保持速度模长，0.02秒步长的参考转角不超过1.81度。

上述全部通过。证据：`Temp/CourseLock/component.json`。
