# Unity 6.6 后续适配

本轮依据原升级报告推进 P1 兼容修复、主要场景回归和 Windows Development Player 验证；没有再次更换引擎或包版本。Unity 6000.6.8f1、URP/VFX Graph 17.6.0、Input System 1.20.1。

## 已落地

- 当前 HEAD 的自有源码实际有 84 处 `FindFirstObjectByType<T>` 调用，已全部迁移；原报告记录的 85 处以本轮实际搜索为准。全局单例/存在性检查使用 `FindAnyObjectByType`，场景服务通过 `SceneObjectQuery` 明确按拥有者或活动场景查询。同场景重复服务抛出明确异常，不依赖创建顺序。PlayManager 的敌人调度、阵地战 HUD/威胁标记使用组件自己的场景。
- VFX 桥接使用 `CurrentAssemblies.GetLoadedAssemblies`。实际回归发现 VFX 17.6 已移除 `GetOrCreateGraph`，改为 `GetGraph` / `CreateGraph`；缺失类型、方法产生包含名称的诊断。12 份自有图的临时副本验证了内部类型、图节点、参数、属性设置、槽位值/连接、保存、重导入及参数重载，完成后由 AssetDatabase 删除副本，未重写原图。
- 审计 104 个使用旧 External 设置的 FBX；103 个禁用材质导入，仅 FX Exhaust 启用。仅迁移该资源到 InPrefab，并将原外部材质显式 remap。实际重导入前后模型 GUID、网格 localId、100 顶点/384 索引、bounds 和材质 GUID/localId 均一致。保留源 FBX 与原 `.meta` GUID，其他模型没有批量重导入。Editor 同时更新 importer 序列化版本及新增默认字段。
- Development 构建额外暴露 3 个 VFX 网格依赖旧的自动开启 Read/Write 补偿；只对自有资源库中的 firestreak、shockwave_ground、third 显式启用。重导入前后 GUID/localId、顶点/索引数量和 bounds 一致（分别 36、65、65 顶点），消除该构建警告；不修改第三方源包。
- Profiler 分析器不再调用弃用的 Statistics API，使用录制帧内的类型化 counter。保留有效零值、原始单位、已采集帧覆盖率；缺失值不计入平均、不补零。GPU 层级时间按该录制帧的 Gathered 标志判断，Frame Timing counter 单列，不能混为同一测量。分析当前可用的 345 帧存量捕获验证读取能力，不将其称为本轮新性能基准。
- InputManager 用运行时 `Debug.isDebugBuild` 判断 Player 开发工具权限，保留 Editor 可用性，消除 `DEVELOPMENT_BUILD` 新弃用警告。
- CodeReadability 分别从实际生成的 Assembly-CSharp.csproj / Assembly-CSharp-Editor.csproj 读取完整 DefineConstants，保留运行时程序集与 Editor 程序集不同的 .NET 条件符号，拒绝缺少 `UNITY_6000_6_OR_NEWER` 的过期文件；仍是 Windows Editor 的解析上下文，不能代表全平台条件编译验证。
- Development 构建入口使用一次性 Editor update 调度，避免失焦窗口延迟执行；显式 Siege Player 探针支持从构建入口 Main 加载 Siege，实际覆盖场景切换。没有改动正常启动流程或自动版本号。
- Main 会话探针原有两处断言已经落后于生产契约：建筑只从共用文件仓读取，死亡先显示重生界面。更新为当前规则，并共用现有世界模板范围校验，不恢复已废弃的打包示例回退，不通过测试写玩家存档。
- Player 实测发现地形列提交与远景环协程刷新存在同步空窗，Editor 同样可复现，移至 LateUpdate 的检查仍失败，不能归结为探针误报。改为 ProceduralVoxelWorld 在加载/卸载提交时同步通知 WorldDistanceView，直接更新该列可见性；清空时刷新、Dispose 时取消订阅。原来的分帧网格构建和版本兜底保留，没有改为逐帧全量扫描或降低远景质量。新增提交瞬间的加载/卸载回归；Player 探针仍保留原断言，并放在 LateUpdate 检查最终表现状态。

Windows x64 Mono Development 最终构建成功：0 错误、1 警告、10.87 秒、481,519,168 bytes。最终包实际启动，D3D11、1280×720：Main 固定种子 14721 的 33 项检查通过，完成地形旅行、远景重叠检查、退出/重新准备以及独立缓存文件仓中的返航保存/重载、死亡清货、重生和再次出发；Siege 从 Main 加载，67 项检查通过，包含真实损伤刺激、修复/驾驶接管及场景重启，均无探针捕获的 Error/Exception。两次进程按探针正常退出。

唯一构建警告是 Pipeline 未配置 RuntimePipelineConfig，故 Player 禁用 Pipeline 服务；这是 Editor 自动化插件的运行时连接功能，验证包不需要向外开放该服务。本轮没有为消除警告而开启 Player 自动化端口。早期完整构建还报告 TMP 第三方 shader 的旧 debug pragma 及两个隐藏调试 shader stripping；最终增量构建未重复输出，不据此宣称第三方源码问题已修复。

保留失败过程：旧 Main 会话断言和测试访问级别已修正；第一次 Main Player 的远景重叠失败、改 LateUpdate 后仍失败，均保留在 Logs。同步列通知后 Main Player 与即时回归通过。最后一轮 Editor 会话曾在 240 秒远距离流式等待处超时，未改阈值，重新完整执行 57 项通过；没有将超时计为通过。初次 VFX 桥接失败定位出移除的方法；修复后的制作回归及 10 类 GPU 生命周期复跑通过。

构建自动写入的 PC shader prefilter、URP runtime-settings 列表和最近场景缓存已备份后还原，避免将构建缓存作为画质改动提交；备份及 SHA256 清单见 Library/UpgradeFollowupBackups。保留运行时 GPU Drawer 等本轮开始前的工程设置。结束恢复 Siege Edit Mode。

## 保留的验收边界

- 已查看 Main、WorldLab 和 VFX 实际图像，未发现粉色缺失材质。没有升级前逐像素基线，不能据此认定 SSAO、HDR/Bloom、全部透明材质、TMP 字体与所有 UI 颜色完全一致，也没有为了过验收降低画质。
- Player 由隐藏窗口启动，生成的屏幕截图是黑帧，不能用作渲染输出验收；Player 通过项仅证明探针记录的运行逻辑、资源可加载、后端和文件行为。最终 Player 画面、GPU Drawer/Shader stripping 的视觉正确性仍需在可见窗口检查，不能以 Editor 图像替代。
- 合成设备检查不代表实体键鼠/手柄、失焦恢复、建造拖拽选择和全过程 UI 导航均已人工验收。当前项目玩法直接读取 Keyboard 的路径也不能因项目 Actions 含 Gamepad 就称为完整手柄支持。
- 本轮不调整物理求解器、Fixed Timestep、伤害、飞船数量或画质；大规模断裂、坍塌、机器人停靠、高速投射物及长时战斗性能仍须用固定场景/设备重新采集。
- 本轮目标是 Windows x64 Mono Development；IL2CPP、Android/Mobile 管线及其他图形 API 未覆盖。P3 包/闲置资产清理没有引用和构建占用证据，暂不删除。
