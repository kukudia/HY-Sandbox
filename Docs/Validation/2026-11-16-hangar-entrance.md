# 机库前门／顶门 · 2026-11-16

本轮增加真实可编辑开口方向，沿用旧前门默认值，不改个人蓝图。当前支持前门（随整体竖轴旋转）和顶门，不支持任意面板位置。

## 实现与恢复

- `BlockData.hangarEntrance` 使用 Front=0 / Roof=1；恢复工厂、保存、建造复制与撤销重做共用此字段。未知值在部署/恢复前拒绝。
- 顶门将同一2×2×1无重叠墙块划分旋转到屋顶开口，按实际模块数报价；旧前门墙块顺序和损伤快照版本保持，避免读档补回已毁模块。
- 真实Prefab四面尺寸控件增加 DOOR 按钮，原有节点与GUID保留；制作入口 `HangarPrefabAuthoring.AddEntranceControls()` 保存唯一时间戳备份到Library/HangarEntrance，再更新真实Prefab。
- 门板和防夹查询随开口方向变化。导引不改变船体朝向，垂直出库/直返，偏轴返航先升到安全高度、对齐顶门，再下降。仍由真实电网/推进能力限制。
- 恢复点：本轮前 HEAD 34725ef3；没有删除个人基地文件。

## 剩余边界

尚未覆盖多机库同时拥挤、上方人为封堵、全部舰型及独立Player中的方向交互。通道堵塞仍可能超时，按原规则报废；这不是自动路径规划系统。顶门垂直路径主要使用升力，普通水平喷口无需伪造输出。
