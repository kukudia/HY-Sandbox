# 连续升降、局部路线接续与速度轨迹

场景入口：`Assets/Scenes/EnemyAvoidanceLab.unity`。生产行为由 `EnemyController.ApplyObstacleAvoidance`、`EnemyObstacleClimb.ForwardRatio` 和 `EnemyLocalPath.TryFollow` 实现；蓝图、推进器、供电及真实碰撞链保持运行。

## 当前规则

- 高度差不再直接把水平推进归零。按整舰从当前高度到目标高度的完整升降区间扫掠前方，使用可用距离、1.5m/s 的保守升降估计及实际水平速度计算滑行余量，再限制水平推进。近障仍可收油至零，最终输入仍去除反向推进，不通过写刚体速度制动。
- 翻越最高点后是否更新路线，取决于整舰后续通道是否已畅通；仅飞船中心到达最高点不足以证明机尾已越过障碍。缓存路线每次决策复查前方局部窗口，通往目标方向的整舰通道恢复后即提前直达，不再飞到旧路线末点。日志理由为 `GoalVisible`，此处表示局部窗口通畅，不承诺窗口外全程无遮挡。
- 仍需绕障时，仅在已进入路线最后一段、距离局部终点小于搜索半径35%时滚动更新；默认半径96m对应约33.6m，最短重规划间隔仍为2秒。新搜索失败且旧段已验证安全时，保留旧路线（`FollowingRetained`）。避免在关键转弯前随意换线。局部窗口终点若尚未到任务目标，会在净空允许时保持该段最高航层，避免窗口边缘恰好位于下一堵墙前而提前下降。
- 正常接敌高度2m内的悬浮误差不会被规划器继续当作更低航层；先验证垂直净空，再把栅格起点对齐正常高度，减少低空路线失效。路线结束或重规划失败时，也要验证整舰下降及下层前向通道；未通过则保留最后安全高度，不能直接恢复低空悬浮设定。
- 飞行轨迹按采样时实际三维速度着色，深蓝慢、浅青快。默认固定0–8m/s，可在试验场 Inspector 的 `Trace Fast Speed` 调整。速度沿累计路程重采样为2048像素纹理，保留历史路段变化；总览/透视和Scene Gizmos使用相同标尺。到达后轨迹冻结在最后记录时刻，橙色规划线保持原含义。

## 实船对比

`EnemyLabEfficiencyChecks.Begin(label)` 按固定顺序部署内置 Finch，测试单墙、顶棚 U 型、高墙、下穿、城区东西向和城区北线。测试临时使用3倍时间速度，物理固定步长保持不变，结束恢复时间设置。耗时为模拟时间；到达采用试验场原有水平半径判定，不能视为精确停靠。会话记录位于 `Application.persistentDataPath/NavigationLabRecords/`。

## 验证与限制

- Unity 6000.6.8f1 导入编译成功；63项 `NavigationCombatPlayChecks` 通过，新增远障允许爬升前进、近障收油、越障后提前释放旧路线、重新规划、下降保高与局部窗口峰值保持检查。
- 29项 `EnemyLabPlayChecks` 通过，覆盖部署、点选、暂停恢复、输入记录与十二布局切换。
- 已在真实运行中检查速度纹理：URP Unlit 材质、2048像素纹理及不同深浅像素，查看总览截图。资源随禁用释放并恢复原材质，重置时清空历史速度。
- 可读性检查0错误；解决方案静态构建0错误、37条既有警告。未运行独立Player构建和全蓝图/全起终点组合测试。
- 中途实验版本出现过惯性撞墙、绕墙切角和下降漏检楼顶，均未作为交付结果；最终对比使用完整高度区间扫掠与接敌航层对齐。现有A*节点预算、局部搜索半径和载具推进能力仍会限制复杂场地可达性。
