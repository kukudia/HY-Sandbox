# 远场信息驱动路线规划

场景 `Assets/Scenes/EnemyAvoidanceLab.unity`，Unity 6000.6.8f1。延续远场感知，解决原先远场信息在驾驶路线生成后才采集、只能提示或调速的问题。[源码函数图](../RuntimeFlow.md)；[前版基线](2026-11-12-navigation-perception.md)。

## 生产主链

`EnemyController.ApplyObstacleAvoidance → EnemyNavigationPrediction.Observe → EnemyLocalPath.TryFollow → 航点跟随 → EnemyNavigationPrediction.Choose`。

- Observe 先采集一次周向 OverlapBox 并预读最多四段旧路线或任务方向。沿用80米、8身位、10秒航程取最大值，上限160米，最多256碰撞体。
- RouteBlocked / CrossingWatch 请求 FarRouteBlocked / FarCrossing；A* 复用同一份 Bounds、速度和角速度快照，覆盖完整远场视距，不再只规划到原96米窗口的80%。近场 Choose 也复用快照，不重复物理采集。
- A* 按整舰旋转包络与净空扩张障碍，移动障碍使用短期运动包络，最多3秒，平移/旋转余量各限12米。默认节点预算1024、冷却2秒不变，保留转弯代价、限额航点简化和安全旧路线回退。
- 远场风险优先尝试规划；无运动障碍且采集未饱和时，已承诺的安全升降继续执行，A*失败或冷却期间允许安全升降回退；有运动障碍时风险优先交还快照规划和近场让行。
- 感知饱和封锁规划并请求制动。关闭预测时沿用独立物理采集的局部规划；启用/禁用清理快照引用和规划请求。无新增序列化字段、资产或存档迁移。

## Play Mode 验证

EnemyPredictionPlayChecks 29项通过，NavigationCombatPlayChecks 75项通过。新增隔离物理验证在100米外放置高墙，近场尚未到达风险区时预读挡路；随后禁用墙碰撞体并将规划层掩码置0，证明A*仍使用已采集快照，突破原96米窗口生成侧向绕行航点。重复风险提示不突破冷却，扩展不超过1024，Choose复用快照而不重新采集。

实船使用内置Finch，原六路线顺序、固定0.02秒物理步长、3倍时间速度、22米水平到达半径及2秒等待。实体ID、物理误差和动态相位会影响结果，不能由单轮推导普遍最优性。

早期实验确认“远场风险始终禁止爬升”会使顶棚U型绕远；交付版已保留规划失败后的静态安全升降回退。未限制运动障碍时，城区一次复测发生5次墙体接触；交付版禁止在这类风险下使用仅检查静态净空的爬升回退。另尝试在原节点预算内比较多个终点连接候选，实飞开销增加且未改善表现，未纳入交付。

这是有限视距局部规划，并非全图搜索或时间扩展A*。动态信息仅作为短期包络，不能准确预测远期反向、其他驾驶员决策或推进器误差；NoSafeCandidate仍可能出现。不保证任意蓝图、多舰压力或所有动态相位均安全、最短或转向最少。地面接触与墙体接触单独统计。
