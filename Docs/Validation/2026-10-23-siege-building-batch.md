# 建筑范围损毁批处理

2026-10-23，Unity 6000.3.11f1 Editor Play。

## 已测问题与实现

原先一轮范围伤害摧毁42块，会同步执行42次全建筑支撑遍历。两层1024个1m模块夹具中，单次范围伤害中位879.25ms、252630次物理邻接查询。生产实现现将同轮命中和排队连锁先结算，最外层批次结束时每栋脏建筑执行一次支撑/质量/子组件刷新。直接弹丸触发爆炸也纳入该生命周期；非爆炸单块死亡仍在调用返回前完成支撑。

有意修正：同轮命中的模块先收到伤害，再转换残骸，避免先断开的模块被禁用而跳过该轮伤害。核心销毁事件仍即时发出；批次结束后，核心脱离主体也会被会话识别为失败。

尝试建筑复用舰船双侧连接缓存后，冷建图和整个损毁反而变慢：1024块冷支撑357.02ms、后续损毁79.12ms，虽然后续物理邻接查询为0。该路线已撤回，生产建筑保留几何支撑遍历；报告siege-building-cpu-cached.json仅是失败实验数据，不能称缓存加速。
