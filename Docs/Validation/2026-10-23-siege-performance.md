# 2026-10-23 阵地战性能基线

环境：Windows、Unity 6000.3.11f1 Editor，最新32模块单连通基地、默认种子14741；两艘购买舰Finch/Pike，首艘玩家驾驶、其余友方AI，首波2敌机。只本地采样，不是正式Player或GPU性能。

## 自然交火窗口

90.00秒，6702次推进帧观察，无漏观察帧。Editor观察间隔中位12.62ms、P95 16.22ms、P99 20.38ms；包含编辑器调度、渲染和观察开销，不能直接作为游戏Player FPS承诺。

10次刷新累计：连接遍历19.89ms（单次最大2.74ms），物理组重建90.49ms（最大15.57ms），整段刷新163.48ms（最大23.63ms）。这是嵌套计时：刷新包含重建，重建包含连接，不相加。输入块枚举早于完整刷新计时，不包含在内。单次样本不足以证明稳定加速比，但说明只优化BFS不能消除整体重组开销。

低频规模峰值：483模块、85运行单位、81无驾驶舱碎片、490碰撞体、86刚体、69醒着的动态刚体。峰值不一定发生在同一秒；每秒一次查询可能漏过短暂峰值。窗口末金币1770，1敌机存活，不能称首波完成。

见 [摘要与每秒场景规模](2026-10-23-siege-natural-baseline.json)、[完整原始观察gzip](2026-10-23-siege-natural-baseline.frames.json.gz)。解压后SHA256应匹配摘要rawSha256。GC来自Profiler最后值，可能重复/滞后，不累加为分配总量。采样器每秒全场查询会分配；报告不能用于声称无分配。

## 同步连接图夹具

真实1x1x1预制体链100/256/1024模块，每规模1次预热和7次计时，不初始化连接视觉、不推进物理；仅用于连接查询CPU基线。创建与清理不计入，GroupBlocks内部物理同步计入。完整数据见 [拓扑基线](2026-10-23-siege-topology-baseline.json)。

在100块链中断开中间模块后，正序和倒序均报告2组，但各组成员不同，断开块未在两种顺序下都独立成组。已确认这是几何查询方向与碰撞层组合产生的正确性缺陷，优化前先修复；不隐藏失败结果。

GC.GetAllocatedBytesForCurrentThread增加已知4096字节分配校准；不响应时标记不可用并记录-1。初次实验返回全0，不能据此称无分配；归档为带校准的新实验结果。

## 断链对称性修复

`BlockConnections` 现在要求查询源和目标的规范碰撞体都能参与连接层；关闭碰撞体、断链退出连接层或禁用方块时，不允许只从其中一侧形成关系。DisConnect保存每个碰撞节点的原Layer，显式Restore恢复，不把特殊子层统一改成Block。修缮与建筑底座Configure接入恢复。

真实Play的 [12项拓扑检查](2026-10-23-siege-topology-checks.json) 通过，覆盖正倒序三单块、重复断开、多Collider共节点/特殊子层、同帧移动、禁用连接面/碰撞体、无视觉、输入去重、底座生成和扩缩。最新 [20项闭环检查](2026-10-23-siege-play.json) 使用实际DisConnect后再维修，确认机体单连通。

[同样链条的修复后记录](2026-10-23-siege-topology-symmetric.json) 确认正反遍历模块归属一致，断开中间块独立，两侧各自为一分量。此提交修正确性，不宣称性能优化；它增加了参与状态校验，CPU后续需单独优化。

既有 `BuildPalettePlayProbe` 在Main真实Play的102项检查通过，0错误，覆盖原连接视觉、同帧移动、禁用面和完整建造UI回归。检查结束Main干净，已返回Siege；见 [Main回归](2026-10-23-siege-build-regression.json)。
