# 随速度增加避障提前量

前向扫掠距离 = 基础距离 + v×t + v²/(2a)。v为实际刚体速度大小，t为预判时间与移动采样周期的较大值，a为Inspector中的predictionBrakingAcceleration（默认6m/s²，下限0.1）。默认t=1.5s、基础距离12m：4m/s约19.3m，10m/s约35.3m，20m/s约75.3m。垂直避让检查距离取基础50m与当前扫掠距离的较大值。

减速度仅用于预判距离余量，遇障仍减小推力、禁止反推。保留原当前速度方向、低速起步、上下净空及高度保持规则。

Unity6000.6.8f1编译通过；NavigationCombatPlayChecks 45项Play Mode回归通过，新增实际生产查询距离比较4m/s与20m/s，确认高速预判更远。静态编译与格式检查通过。极限高速、复杂下穿及密集世界查询开销尚未验证。

实船复测未通过：Single wall在墙边停止，90秒超时、11次接触。将生产距离公式临时恢复至HEAD旧公式后，同一场景仍复现墙边停滞（28.6秒，12次接触，速度接近零，目标高度回落至6米）。因此该问题也存在于旧公式，不能据此宣称本轮提前量修改已通过实船验收。对照结束后已恢复本轮公式；未保留实验性的高度保持与航向调整。避障高度丢失及整舰碰撞仍需单独修复，极限高速实船尚未验收。
