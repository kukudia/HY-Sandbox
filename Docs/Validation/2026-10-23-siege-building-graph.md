# 建筑几何邻接缓存验证

2026-10-23，Unity 6000.3.11f1 Editor Play。本次在范围损毁批处理之上缓存单栋建筑的实际几何邻接，不创建双侧连接视觉，不改变虚拟底座支撑、核心或残骸规则。

## 失效与回退

每轮检查存活模块、局部姿态、连接面身份/几何、规范BoxCollider、层/查询掩码、trigger、连接参与状态、根缩放和连接坐标节点。整体刚体平移/旋转保持邻接。新增或配置改变全图重建；删除模块按保守探测范围重查附近存活模块，再移除节点，覆盖原先遮住候选但未形成边的模块。直接连接子节点记录局部变换与实例ID，销毁引用不能被Unity伪null漏掉。额外碰撞体、深层连接节点等复杂布局每次实时重建；恢复规范布局再重建一次后可缓存。

删除范围判定当前是存活节点×删除节点的距离检查；大量同时删除仍有CPU增长，尚未替换为空间索引。节点字典与列表保留到所属建筑销毁，无跨建筑全局缓存。
