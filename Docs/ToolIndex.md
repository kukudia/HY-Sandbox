# 自有开发工具入口

这些工具不属于游戏每帧调用链。资产/蓝图生成会写文件，Unity eval_file 探针可能写用户目录；本轮对外围工具仅执行静态检查，未运行这些生成入口。运行前阅读脚本顶部的输出与环境说明。C#主工程函数见 [CodeIndex](CodeIndex.md)。

| 文件 | 职责 / 入口 |
| --- | --- |
| [ArtSource/VfxGraph/prepare_textures.py](../ArtSource/VfxGraph/prepare_textures.py#L12) | Convert manifest-listed UNI TGA sources to PNG and verify unchanged pixels. |
| [ArtSource/VfxGraph/verify_assets.py](../ArtSource/VfxGraph/verify_assets.py#L146) | Audit tracked VFX assets and compare saved Unity Play Mode probe images. |
| [Blueprints/CODEX/Generate.cs](../Blueprints/CODEX/Generate.cs#L5) | 职责：生成五份玩家蓝图，读取真实部件并将差异存档备份后写入仓库和 Saves。 入口：unity command eval_file --file Blueprints/CODEX/Generate.cs --json；在连接的 Editor 中执行。 Run in the connected HY-Sandbox Editor: unity command eval_file --file Blueprints/CODEX/Generate.cs --timeout 60000 --json Uses shipped prefab dimensions and stock stats. Existing different saves are backed up, never silently overwritten. |
| [Blueprints/CODEX/RuntimeProbe.cs](../Blueprints/CODEX/RuntimeProbe.cs#L5) | 职责：在 Main Play Mode 逐艘加载玩家蓝图，模拟输入并记录 Runtime.tsv；结束时退出运行。 入口：unity command eval_file --file Blueprints/CODEX/RuntimeProbe.cs --json；探针需先进入 Main Play Mode。 Optional short automated Play Mode smoke test. Requires the Main scene already in Editor Play Mode. Changes only temporary runtime state; does not save a scene or modify any existing player blueprint. |
| [Blueprints/CODEX/Validate.cs](../Blueprints/CODEX/Validate.cs#L5) | 职责：读取玩家蓝图，核对真实 Prefab、连接图、部件能力和无线供电覆盖。 入口：unity command eval_file --file Blueprints/CODEX/Validate.cs --json；在连接的 Editor 中执行。 unity command eval_file --file Blueprints/CODEX/Validate.cs --timeout 60000 --json Exact stock connector geometry and capability checks, plus wireless coverage and duplicate-ID checks. |
| [Blueprints/CODEX_Enemies/FlightProbe.cs](../Blueprints/CODEX_Enemies/FlightProbe.cs#L5) | 职责：在 Main Play Mode 测量敌机悬停、追踪和失去目标后的飞行，记录 Flight.csv。 入口：unity command eval_file --file Blueprints/CODEX_Enemies/FlightProbe.cs --json；探针需先进入 Main Play Mode。 Run in Main Play Mode using eval_file. Uses the real EnemySpawner and EnemyController. Disposable runtime changes only. Test ends by exiting Play Mode; never run during unsaved runtime editing. |
| [Blueprints/CODEX_Enemies/Generate.cs](../Blueprints/CODEX_Enemies/Generate.cs#L5) | 职责：生成三份敌机蓝图并写入仓库和 EnemyBlueprints；拒绝覆盖不同内容。 入口：unity command eval_file --file Blueprints/CODEX_Enemies/Generate.cs --json；在连接的 Editor 中执行。 Execute using unity command eval_file --file Blueprints/CODEX_Enemies/Generate.cs --json Stock parts only; deterministic IDs, no stat overrides. Refuses to overwrite changed blueprints. |
| [Blueprints/CODEX_Enemies/Summarize.ps1](../Blueprints/CODEX_Enemies/Summarize.ps1#L5) | 职责：读取 Flight.csv 与基线，计算完整供电飞行指标并写入 Flight-summary.json。 入口：在 FlightProbe 完成后运行此脚本；不启动新的飞行测试。 Run after FlightProbe completes. Thresholds describe intact, powered flight, not battle survivability. |
| [Blueprints/CODEX_Enemies/Validate.cs](../Blueprints/CODEX_Enemies/Validate.cs#L5) | 职责：读取敌机蓝图，核对真实 Prefab、唯一 ID、连接图和无线供电覆盖。 入口：unity command eval_file --file Blueprints/CODEX_Enemies/Validate.cs --json；在连接的 Editor 中执行。 unity command eval_file --file Blueprints/CODEX_Enemies/Validate.cs --timeout 60000 --json Exact stock connector geometry and capability checks, plus wireless coverage and duplicate-ID checks. |
| [Blueprints/DSH_Enemies/ArmamentProbe.cs](../Blueprints/DSH_Enemies/ArmamentProbe.cs#L1) | 职责：在 Main Play Mode 逐艘验证炮塔供电、转向锁定和弹道出膛，写出 Armament-summary.json。 入口：进入 Main Play Mode 后 eval_file；探针结束自动退出 Play Mode。 DSH armament probe. |
| [Blueprints/DSH_Enemies/design_model.py](../Blueprints/DSH_Enemies/design_model.py#L1414) | Offline geometry, mass and power model; importing it never writes assets. |
| [Blueprints/DSH_Enemies/FlightProbe.cs](../Blueprints/DSH_Enemies/FlightProbe.cs#L23) | 职责：在 Main Play Mode 逐艘测量悬停、追踪和冲量恢复，记录 Flight.csv。 入口：unity command eval_file --file Blueprints/DSH_Enemies/FlightProbe.cs --json；探针需先进入 Main Play Mode。 DSH enemy flight probe.  |
| [Blueprints/DSH_Enemies/Generate.cs](../Blueprints/DSH_Enemies/Generate.cs#L38) | 职责：使用离线模型生成的布局写入仓库和 EnemyBlueprints，拒绝覆盖不同内容。 入口：unity command eval_file --file Blueprints/DSH_Enemies/Generate.cs --json；在连接的 Editor 中执行。 DSH enemy blueprint generator.  |
| [Blueprints/DSH_Enemies/power_check.py](../Blueprints/DSH_Enemies/power_check.py#L19) | Read emitted DSH JSON and report relay coverage and equal-share power. |
| [Blueprints/DSH_Enemies/summarize.py](../Blueprints/DSH_Enemies/summarize.py#L35) | Summarise the saved DSH enemy Flight.csv; no files are written. |
| [Blueprints/DSH_Enemies/Validate.cs](../Blueprints/DSH_Enemies/Validate.cs#L21) | 职责：比对仓库与安装蓝图，并用真实 Prefab 验证连接、体积、供电、升力、驾驶舱六面遮蔽、弹道炮塔和吊舱。 入口：unity command eval_file --file Blueprints/DSH_Enemies/Validate.cs --json；在连接的 Editor 中执行。 DSH enemy blueprint validator.  |
| [Blueprints/DSH_Enemies/write_generator.py](../Blueprints/DSH_Enemies/write_generator.py#L272) | Write Generate.cs from the DSH design model; importing does not generate files. |
| [Tools/CodeReadability/check_tool_sources.py](../Tools/CodeReadability/check_tool_sources.py#L46) | Check offline tool entrypoints and syntax without executing asset or save writers. |
| [Tools/CodeReadability/generate_flow_browser.py](../Tools/CodeReadability/generate_flow_browser.py#L10) | Generate the interactive runtime diagram viewer from RuntimeFlow.md. |
| [Tools/CodeReadability/generate_navigation.py](../Tools/CodeReadability/generate_navigation.py#L7) | 职责：由实际 Roslyn 符号生成函数导航；图规格在本文件按功能维护。 入口：python Tools/CodeReadability/generate_navigation.py |
| [Tools/CodeReadability/Program.cs](../Tools/CodeReadability/Program.cs#L3) | 职责：用 Roslyn 校验/整理自有脚本格式、脚本介绍和函数图导航，输出可审查的复杂度提示。 入口：dotnet run --project Tools/CodeReadability -- --check <project-root>；--write 显式写入。 |
