# HY-Sandbox 卡通工业玩具美术规范

## 核心气质

整体像一套可拆装的卡通工程玩具：方正大块面、清晰色块和适度高光负责亲和力与可读性，借鉴 Dyson Sphere Program 的功能色阶与 Trailmakers 的模块化玩具比例。配色借鉴真实工业材料而不是统一黑色。造型允许夸张，但不能改变模块占用尺寸、碰撞体、连接点或存档身份。

## 形状语言

- 结构块：六面一致的长方体/正方体喷涂钢壳，使用硬边制造清晰堆叠缝，不添加顶部/前部方向性装饰。
- 驾驶舱：低矮装甲船体、前倾玻璃座舱、青色状态脊线。
- 动力：宽口喷嘴、收束机匣、琥珀热端；喷射方向仍以原脚本的局部轴为准。
- 能源：悬浮核心与低面数同心环，动画只作用于视觉子节点。
- 工具与武器：明确的基座、转轴和工作端；主体以盒体为骨架，再用少量楔体、圆柱和发光件表达功能。

## 性能预算

- 当前所有模块暂时禁用 LOD：仅保留一套可见视觉层，方便卡通材质和轮廓调校；后续重新启用时需在目标镜头下验证切换距离。
- 材质开启 GPU Instancing，所有程序化模型复用共享 Mesh 与 Material。
- 动画仅旋转或浮动 Transform，并使用 MaterialPropertyBlock 脉冲自发光，不实例化材质。
- 视觉 Mesh、碰撞体、连接点和 Block 数据严格分层；美术更新不得改变物理与存档协议。

## 资源生成

通过 `Tools > HY Sandbox > Rebuild Industrial Art` 可重新生成共享 Mesh、材质、全部模块视觉层及预览场景。生成器保留 Prefab 根组件、碰撞体、`Connectors`、`Debug` 和嵌套 RepairBot，只替换 `Model` 下的旧占位渲染节点。
